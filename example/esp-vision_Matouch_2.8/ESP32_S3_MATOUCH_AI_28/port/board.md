The following firmware is applicable to the Makerfabs MaTouch ESP32-S3 SPI TFT
with AI 2.8 board.

This board has 16 MiB external SPI Flash, 8 MiB Octal PSRAM, an OV3660 DVP
camera, and a 240x320 ST7789V SPI LCD used in 320x240 landscape orientation.
The default configuration enables native TinyUSB CDC/MSC and UART REPL.
